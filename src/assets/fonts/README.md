# Polices locales de remplacement

Noto Serif Regular, Bold, Italic et BoldItalic proviennent du dépôt officiel :

https://github.com/notofonts/noto-fonts/tree/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf/NotoSerif

Révision : `ffebf8c1ee449e544955a7e813c54f9b73848eac`.

Les fichiers TTF complets sont distribués sans modification sous SIL Open Font License 1.1 ; le texte et les mentions de copyright sont conservés dans `OFL.txt`. Le script de préparation copie également cette licence dans les ressources de l'application distribuée.

Le moteur réutilise prioritairement les glyphes du PDF. Les fichiers locaux servent uniquement aux caractères absents d'une police Noto Serif compatible ; ils ne sont pas utilisés comme remplacement implicite d'une autre famille.
